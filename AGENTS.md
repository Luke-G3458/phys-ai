# Agents file for Physical Ai

Physical Ai is a Tauri 2.0 app prewired with
- TailwindCSS
- IPC abstractions for frontend and backend
- Global State for frontend
- Custom TitleBar (currently only optimized for macOS)
- Basic resizable pane UI

> See `PLAN.md` for project scope.


**Always format code with Prettier for typescript and cargo fmt for rust after making updates.**
